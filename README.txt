HOME DASHBOARD · V1
===================

STARTEN
1. Doppelklick auf START.bat
2. Der Browser öffnet das Dashboard automatisch.
3. Das schwarze Startfenster geöffnet lassen.
4. Zum Beenden das Startfenster schließen oder dort Strg+C drücken.

Für die Vollbildansicht im Browser F11 drücken.

ÜBERTRAGEN
Der gesamte Ordner ist portabel. Einfach auf ein anderes Windows-Benutzerkonto
kopieren und dort START.bat öffnen. Es ist keine Installation erforderlich.

INHALT
- Große Uhrzeit und Datum
- Live-Wetter für Berg TG mit 5-Tage-Vorschau über Open-Meteo
- Live-Wetter für Rastatt und Monchique
- Beispieldaten als automatischer Offline-Fallback
- Einkaufsliste; Einträge werden lokal im Browser gespeichert
- Offene Artikel direkt als PDF oder Notiz teilen
- "Eingekauft" öffnet zuerst eine Auswahl; nur bestätigte Artikel werden entfernt
- Nicht ausgewählte Artikel bleiben automatisch für die nächste Liste erhalten

WETTER-API
Das Dashboard nutzt Open-Meteo (https://open-meteo.com/). Für die normale
private Nutzung ist kein API-Schlüssel nötig. Die Wetterdaten werden beim Start
und danach automatisch alle 15 Minuten aktualisiert.
